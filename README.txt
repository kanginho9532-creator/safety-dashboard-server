# 안전관리 통합 대시보드 사용 설명서

## 1. 실행 방법
1. 압축 파일(safety-dashboard.zip)을 원하는 폴더에 풀어주세요.
2. `safety-dashboard.html` 파일을 더블클릭하면 크롬/엣지 브라우저에서 바로 열립니다.
3. 데이터는 브라우저의 localStorage에 저장되어, 같은 브라우저에서 다시 열어도 방문일자/연락요청일자 기록이 유지됩니다.
4. 스마트폰에서 쓰려면: 이 파일들을 Netlify Drop(https://app.netlify.com/drop)에 폴더째로 드래그하면 무료 URL이 생성됩니다.
   생성된 사이트를 모바일 브라우저(Chrome)에서 열고 "홈 화면에 추가"를 누르면 앱 아이콘처럼 사용할 수 있습니다(manifest.json 포함).

## 2. 이번 업데이트 반영 내용
- 탭 메뉴를 상단에서 좌측 사이드바로 이동했습니다.
- 계약관리 탭 추가: 최근 수정일(Notion lastEdited) 내림차순 정렬, NO 자동 부여, 검색창 포함.
- 공사명 클릭 시 상세보기가 모달(팝업) 창으로 열립니다. 기존 별도 "상세보기" 탭은 삭제했습니다.
- 대시보드 상단 핵심 요약에 "이번달 총 방문 횟수" 카드를 추가했습니다.
- 우측 상단 "AI 이번주 주중 방문 스케줄"에서 일~토 형태로 조건(하루 4곳, 현대제철 최대 3곳/중복시 4곳, 주말 제외, 월 2회 미달 현장·미방문 현장 우선)을 반영한 추천 일정을 자동 생성합니다. 이 결과는 노션에 자동 반영되지 않으며, 확인 후 캘린더에서 직접 드래그로 등록해야 합니다.
- 이번달 미방문 현장 목록에 "1/2 방문" 형태의 진행률 배지를 표시합니다.
- 비고(note)에 내용이 있는 현장은 공사명 옆에 빨간 "!" 표시가 뜨며, 마우스를 올리면 사유가 보입니다.
- 캘린더에서 일정 클릭(선택), Ctrl+클릭(다중 선택/해제), 일반 드래그(이동), Ctrl+드래그(복사)가 모두 동작하며, 이동/복사 시 상세보기에 표시되는 최신 방문일자도 함께 갱신됩니다. Esc 또는 빈 공간 클릭 시 전체 선택이 해제됩니다.
- 우측 하단 "💬 수정요청 챗" 버튼을 누르면 수정 요청을 기록할 수 있는 채팅창이 열립니다. 다만 이 창은 요청 이력을 저장하는 기능이며, 실제 코드 반영은 대화(Perplexity 챗)에서 요청하신 뒤 파일을 다시 받아 교체해야 합니다. 브라우저 단독 페이지에서는 AI가 자기 자신의 코드를 실시간으로 고쳐 쓸 수 없기 때문입니다.

## 3. DeepSeek / Notion API에 대한 중요 안내 (보안)
요청하신 DEEPSEEK_API_KEY와 Notion API 키는 이 문서에 포함하지 않았습니다. 그 이유는:
- 이 HTML/JS 파일은 브라우저에서 그대로 실행되는 "정적 파일"이라, 코드 안에 API 키를 넣으면 파일을 열어본 누구나 개발자도구로 키를 확인하고 복사해 갈 수 있습니다.
- Notion API와 DeepSeek API는 브라우저에서 직접 호출 시 CORS 정책으로 막혀 있어, 프론트엔드 단독으로는 정상 동작하지 않습니다.
- 따라서 실제 연동을 위해서는 최소한의 서버(예: Vercel/Netlify Functions, 또는 작은 Node.js/Python 서버)를 하나 두고, 그 서버에서만 키를 보관한 채 프론트엔드가 서버에 요청 → 서버가 Notion/DeepSeek에 요청하는 구조가 필요합니다.
- 지금 파일에는 그 대신 "AI 이번주 스케줄"을 요청하신 조건(4곳/3곳 규칙 등)을 그대로 반영한 규칙 기반 로직을 넣어, 실제 DeepSeek 호출 없이도 동일한 결과를 바로 확인할 수 있게 했습니다.
- Notion 실시간 동기화(계약 데이터 자동 불러오기)를 원하시면, 다음 단계로 간단한 서버 코드를 함께 만들어 배포까지 도와드릴 수 있습니다. 원하시면 말씀해주세요.

## 4. 캘린더 오작동(일요일 잘못 드래그) 관련
- 이전 버전은 방문일자를 문자열 하나로만 저장해서 이동/복사가 막혀 있었습니다.
- 이번 버전은 한 현장이 여러 방문일자를 배열로 가질 수 있도록 구조를 바꾸고, 일정 카드 자체를 드래그 가능하게 만들어 이제 어떤 날짜로도 자유롭게 옮기거나 Ctrl+드래그로 복사할 수 있습니다.
